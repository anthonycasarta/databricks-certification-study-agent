# Databricks Certification Study Agent

A Retrieval-Augmented Generation (RAG) study assistant for the **Databricks Certified Data Engineer Associate** certification.

## Overview

This project uses Databricks services to build an AI-powered study assistant that answers certification-related questions using official documentation and study materials.

The goal is to learn data engineering, RAG architecture, AI agent development, and software engineering through hands-on implementation.

## Planned Features (V1)

- Document ingestion and processing
- Semantic search using Databricks AI Search
- AI-generated answers grounded in retrieved documentation
- Source citations
- Private Streamlit chat interface
- Evaluation and tracing with MLflow

## Tech Stack

- **Language:** Python
- **Platform:** Databricks Free Edition
- **Storage:** Unity Catalog and Delta Lake
- **Retrieval:** Databricks AI Search
- **LLM:** Databricks Foundation Model APIs
- **Frontend:** Streamlit
- **Testing:** pytest
- **Code Quality:** Ruff
- **CI/CD:** GitHub Actions
